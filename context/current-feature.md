- Scrollbar Colors: the browser's default scrollbar track renders light, which showed up as a white strip down the right edge of the dashboard's main scroll area against the dark theme. Fixed with one declaration in `globals.css`'s base layer — `scrollbar-color: var(--muted) var(--background)` on `html`, so in dark mode the track matches the page background (`oklch(0.145 0 0)`) and the thumb is a subtle gray (`oklch(0.269 0 0)`). `scrollbar-color` is an inherited property and the theme tokens live on `html` (which also carries the `dark` class), so the main area, the sidebar nav and the mobile drawer all pick it up without per-component classes, and light mode resolves its own token values for free. Took the standard property over `::-webkit-scrollbar` pseudo-elements: it covers Chrome/Edge/Firefox, and Chrome ignores webkit scrollbar rules on an element once `scrollbar-color` is set there, so mixing both would be dead code. Scrollbar width left at the browser default — only the colors changed. Verified the rule in the CSS served by the dev server; build and lint pass.
